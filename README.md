# SecureTask — Web Application Security Lab

## Overview

SecureTask is a hands-on software engineering and cybersecurity project focused on building, deploying, testing, and securing a web application in a virtualized environment.

The project simulates a real-world web application development and security engineering workflow.

## Objectives

- Understand Linux server administration and web hosting.
- Develop a frontend using HTML, CSS, and JavaScript.
- Build REST APIs using Python and FastAPI.
- Integrate PostgreSQL for data persistence.
- Understand web application architecture.
- Identify and exploit common web vulnerabilities in a controlled lab.
- Implement security remediations and verify their effectiveness.

## Technology Stack

| Component | Technology |
|---|---|
| Server OS | Ubuntu Server |
| Web Server | Nginx |
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, FastAPI |
| Database | PostgreSQL |
| Security Testing | Kali Linux, Burp Suite, Nmap |
| Virtualization | VirtualBox |
| Version Control | Git, GitHub |

## Project Phases

1. Infrastructure and Web Hosting
2. Frontend Development
3. Backend Development
4. Database Integration
5. Security Assessment
6. Remediation and Hardening

## Lab Environment

The application will run inside an isolated virtualized environment.

Security testing will be performed against the project-owned application and infrastructure.

## Documentation

Project specifications, architecture, implementation notes, progress logs, and security reports are maintained in the `docs/` and `security/` directories.
